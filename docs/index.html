Features

目前已有的功能模块

小而完整：每个模块都为「顶部常驻、即点即用」而设计，不占任务栏、不打扰工作。

黑胶音乐岛

旋转黑胶唱片与唱臂、专辑封面、进度条与上一首 / 播放 / 下一首，折叠时仅占一条小岛。

逐字渐绿歌词

卡拉OK式逐字渲染，当前演唱字实时点亮；支持换行滚动动画，歌词时间轴可手动微调。

天气速览

折叠态常显当前天气，展开后查看多日详情，天气变化一目了然。

日程页

展开面板内直接查看日程安排，无需切换窗口。

设置中心

主题、透明度、圆角、字号、开机自启、时间格式等，全部在岛内完成配置。

自动更新

每日自动检查新版本，后台下载并显示进度，一键安装后自动重启到新版。
